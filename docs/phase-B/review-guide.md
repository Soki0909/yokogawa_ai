# Phase B Visual Review Guide

技術的な不具合・状態漏れ・主要解像度での崩れは自律検証済みです。久米さんには次の9点だけを、好みと舞台効果の観点で確認いただきます。

1. WARNINGは「異常が起きた」と瞬時に伝わる強さですか。
2. HIJACKEDはWARNINGとは別の、制御を奪われた画面に見えますか。
3. HOSTILEはクライマックスとして十分な強度ですか。
4. Unlock 100%で、いったん成功したと感じられますか。
5. Emergency Protectionへの反転に、十分な落差がありますか。
6. SHUTDOWNの静止・無彩色化に、十分な静寂感がありますか。
7. RECOVERYは段階的で温かな復旧に見えますか。
8. Final Challengeでは問題文が画面の主役に見えますか。
9. NORMAL → WARNING → HIJACKED → HOSTILEという全体の派手さの段階は適切ですか。
