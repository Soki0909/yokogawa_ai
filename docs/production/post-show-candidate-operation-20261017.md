## 緊急操作

Admin「緊急Cue移動」を開き、次にGOするCueを選択 →「移動内容を確認」→ 表示内容を確認 →「確定：停止してこのCueを次にGO」。位置移動自体は再生しません。明示NEXTで開始します。

STOPは進行中の音声・遅延発話を中止し、フェードは対象Cueの最終状態に落ち着きます（P-V00/P-021は表示、P-V08は黒）。REPLAYでそのCueを頭からやり直せます。緊急BLACKOUT/RESTOREは従来どおり独立しています。P-V08からP-021へはRESTORE不要。誤って緊急BLACKOUTした場合はRESTOREが必要です。

Show Reset / Production Reset / Scene 1 rehearsalは開演前の黒へ戻します。他Sceneのリハーサル開始では、それ以前のCueの最終状態を復元します。再接続・再読み込みは安定状態のみを表示し、過去の音声を再生しません。
