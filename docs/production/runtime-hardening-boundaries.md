結果: MERGE 2、KEEP 18、曖昧で新たに統合を保留した境界0。台本の非常停止内容○○とScene5の地の文/実話者の不一致は以前同様に未確定だが、境界を推測して変更しない。既存P-V02+009、P-V06+016、P-V07内復旧は保持。新本編19 Cue。

独立NEXTを意図的に1秒未満で2回出す必要はない。最短AI発話でも約1.4秒以上、さらに他者台詞を挟む。V04→015にも虎谷の命令がある。NEXTは1200msのmonotonic受付間隔。拒否を後送しない。STOP/BLACKOUTは別経路で即応。REPLAY/BACKは現行650msのUI誤操作対策を維持し、NEXT受付間隔を迂回しない。

時間モデル: 主routeと横routeのScene2〜5は4×4分15秒=17分。虎routeは15分45秒。並行routeを足し合わせず、最長17分へ移動・謎解き・集合の8分を加え25分を本番相当と推定。extendedは35分（芝居の約2倍）。少なくとも35分は実時間で放置し、他公演は短いtargeted idleと障害proxyを使う。実際の稽古時間が未提供なので推定を実測と称しない。
