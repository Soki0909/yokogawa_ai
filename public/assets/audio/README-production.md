# Production SFX slots

本番音をこのディレクトリの `production-startup.wav`、`production-hack-noise.wav`、`production-warning.wav` に配置します。16-bit PCM WAV、mono/stereo、推奨44.1kHz。未配置・不正形式はPreflightでMISSING／INVALIDとなり代替音を使います。

server再起動またはAdmin再読込で検証・反映します。詳細と担当Cueは [素材slot手順](../../../docs/production/production-asset-slots.md) を参照してください。
